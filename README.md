# Open Heart Surgery Simulation

**Current proposal: [OHS-PROPOSAL-002 — Android Heart, Animation & Instrument Realism](docs/proposals/OHS-PROPOSAL-002-ANDROID-REALISM.md).** It revisits the engine, heart animation, assets and surgical-tool interaction for Android. The desktop-first proposal below is preserved as an earlier candidate.

**Revision 2:** [second verification](docs/plan/android-review/05-REVERIFICATION.md) adds native Android packaging, explicit pacing/renderer policy, temporal contact synchronization and structural checks of all ten coronary motion files. This remains a plan; no APK or phone benchmark is claimed.

**Heart appearance experiment:** [OHS-HEART-APPEARANCE-001](docs/concepts/heart-appearance-001/README.md) is a generated 2D visual concept for discussion. It is not yet a 3D asset or animation.

**Cannulation realism correction:** [OHS-CANNULATION-REALISM-002](docs/concepts/cannulation-realism-002/README.md) records the new reference-guided appearance target and motion work. The owner rejected the earlier [static storyboard 001](docs/concepts/cannulation-animation-001/README.md) as unrealistic; it remains for history. No 99% resemblance result is claimed.

## المقترح الموحّد / Consolidated proposal

**[OHS-PROPOSAL-001 — Codex Research & Design Proposal](docs/proposals/OHS-PROPOSAL-001-CODEX.md)**

مقترح تخطيطي يجمع البحث والتصميم والمصادر وتراخيص الأصول في ملف واحد. يمكن لأي وكيل قراءته، التحقق من افتراضاته، ومقارنته ببدائل للوصول إلى خطة أفضل. اكتمال البحث لا يعني اعتماد توصياته أو بدء التنفيذ.

The linked document is a named, versioned proposal for review and improvement. It contains the consolidated plan, six design sections, seven research reports, the gap review, and the asset-candidate register. Its opening review prompt tells another agent how to challenge the recommendations and propose a better alternative with evidence.

Status: **proposal for comparison; implementation not started**. The existing Python heartbeat example is an earlier demonstration, not the proposed surgical simulator.

The original modular documents remain accessible through [PLAN.md](PLAN.md). The proposal records the source commit it consolidates; it is a snapshot, not an automatically synchronized duplicate.
